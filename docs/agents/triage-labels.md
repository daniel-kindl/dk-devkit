# Triage labels

Use these labels for the five triage roles:

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | The issue is ready for an unattended agent. |
| `ready-for-human` | A human must implement the issue. |
| `wontfix` | The project will not action the issue. |
